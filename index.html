채널 상태 (🟢라이브 / ⚪오프라인)

실시간 활동 로그

모드

API 키 없이 유튜브 페이지를 직접 읽어서 할당량 제한이 없어요. 다만 너무 짧게(5초 미만) 하면 유튜브가 잠시 요청을 막을 수 있어요.

채널 자동감지 등록 (방송 시작→자동추가, 끝나면→자동제거)

등록된 채널의 라이브 상태는 "현재방송" 탭에서 볼 수 있어요. 종료 감지는 자동으로 저렴하게 항상 돌아가고, 위 주기는 "아직 방송 안 켠 채널"을 확인하는 빈도예요.

검색어 / 해시태그로 1회 추가

24시간 라이브처럼 계속 도는 채널엔 자동주기 대신 위 "채널 자동감지"를 쓰세요. 이건 1회성 수동 검색용이에요.

즐겨찾기 프리셋

방송모드 대체 이미지 (저작권 회피용)

상단 "🔴 방송모드" 버튼을 켜면 모든 영상이 이 이미지로 바뀌고, 꺼면 다시 실제 영상이 나와요. 통계 정보는 방송모드 중에도 계속 갱신돼요.

앱 정보 / 사용 승인

설정 백업 / 복원 (브라우저 저장공간이 초기화될 때 대비)

채널 등록 목록, 검색어, 즐겨찾기를 JSON 파일로 저장해두면, 저장공간이 날아가도 파일로 복원할 수 있어요. (API 키는 보안상 포함 안 됨)
